# 进游戏测试清单

## 卢西奥

- [ ] 自己落地不会把自己弹起来。
- [ ] 半径恢复到约 8 米，但仍然不会影响卢西奥自己。
- [ ] 附近其他玩家会被向上弹起。
- [ ] 不会因为自己或其他卢西奥落地造成无限连环触发。
- [ ] 卢西奥自己只获得短暂加速，不被落地冲击弹飞。

## 天使

- [ ] 每次出生有一次复活甲。
- [ ] 致命伤触发后生命约为 60。
- [ ] 复活甲消耗后，本条命不会再次触发。
- [ ] 周围敌人被击退，队友不应被击退。
- [ ] 自己获得约 1 秒无敌。
- [ ] HUD 显示“复活甲已破碎”。
- [ ] 第二次致命伤正常阵亡，重生后重新获得复活甲。

## 源氏

- [ ] 普通状态下 Shift 不能使用，或会被立刻设置为超长冷却。
- [ ] 源氏击杀后进入 8 秒疯狗窗口。
- [ ] 疯狗窗口内 Shift 可用。
- [ ] 疯狗窗口内大招可用，终极充能变为 100。
- [ ] 击杀后不需要手动按 Q，源氏应立刻进入龙刃状态。
- [ ] 疯狗窗口内再次击杀会把时间重置为 8 秒。
- [ ] 疯狗窗口自然结束后源氏沉睡 5 秒。
- [ ] 源氏死亡后不会残留疯狗窗口，也不会延迟触发沉睡。
- [ ] 换英雄后不会残留疯狗窗口。
- [ ] 大招伤害约为 70；如果龙刃单次仍明显超过 70，需要回看 `事件技能 == 终极技能` 是否识别失败。
- [ ] 其它英雄不受影响。

## 巴蒂 - 哈哈镜

- [ ] 巴蒂斯特开大时触发哈哈镜。
- [ ] 半径 8 米内玩家获得本次随机变形。
- [ ] 当前第一版同一次开大范围内玩家获得同一种镜像效果。
- [ ] 变形持续约 6 秒。
- [ ] 6 秒后体型、速度、伤害、承伤、击退恢复正常。
- [ ] 不会把人弹起来。
- [ ] 巴蒂死亡或换英雄后不会继续重复触发哈哈镜。

## 巴蒂 - 假药注射

- [ ] 巴蒂斯特造成伤害时有约 18% 概率触发。
- [ ] 触发后目标获得一种随机副作用。
- [ ] 目标 3 秒后恢复正常。
- [ ] 巴蒂 4 秒内不会重复触发。
- [ ] 同一目标不会叠多个假药状态。
- [ ] 不会造成额外伤害。
- [ ] 不会影响其它英雄的触发逻辑。

## 索杰恩

- [ ] 滑铲靠近目标会触发。
- [ ] 目标受到 20 点伤害。
- [ ] 目标被击倒约 1.25 秒并铲飞。
- [ ] 索杰恩自己不受伤、不被击倒、不被推开。
- [ ] 同一次滑铲不会连续触发很多次。
- [ ] 半径约 2.6，推力约 18，手感不过分夸张。

## 伊拉锐

- [ ] 造成伤害有约 20% 概率触发晒黑。
- [ ] 晒黑目标变大、变慢、受到击退增加。
- [ ] 晒黑持续约 4 秒后恢复。
- [ ] 再次命中晒黑目标会小幅向上弹飞。
- [ ] 二次弹飞不会因为连续伤害疯狂触发。
- [ ] 技能 2 会弹开附近其他玩家。
- [ ] 技能 2 对空中目标有额外向上弹飞。
- [ ] 伊拉锐自己不会被弹开，并会经历加速、短暂减速、恢复。

## 芙蕾娅

- [ ] 按 E 技能触发时地面出现法阵。
- [ ] 约 0.35 秒后范围内玩家一起高飞。
- [ ] 冷却期间不会重复触发。
- [ ] 范围约 6，高度符合娱乐效果。
- [ ] 法阵效果会自动消失，不会残留。
- [ ] 确认 E 技能触发稳定，不会由普通跳跃触发。

## 安娜

- [ ] 睡针命中后目标有明显玫红光环/标记。
- [ ] 被睡玩家看到“你被睡了”提示。
- [ ] 醒来后标记消失。
- [ ] 不会在沉睡期间一直创建新特效。
- [ ] 原有沉睡冷却惩罚仍然只触发一次，不刷屏。

## HUD 技能说明

- [ ] 左上角仍显示“按住互动键查看技能说明”。
- [ ] 按住互动键显示多行技能说明。
- [ ] 新说明包含天使、卢西奥、索杰恩、伊拉锐、芙蕾娅、安娜。
- [ ] 说明文字没有严重遮挡或过长到无法阅读。
