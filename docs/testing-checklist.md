# 进游戏测试清单

## 变量重构回归测试

- [ ] 技能说明 HUD 仍能用互动键打开/关闭，死亡后不残留也不重复创建。
- [ ] 托比昂零件/非法改装仍正常：零件累计、E 触发、死亡/换英雄清理都符合原逻辑。
- [ ] 堡垒废铁/非法改装仍正常：造成伤害获得废铁，死亡不掉废铁，换英雄清零。
- [ ] 源氏疯狗窗口仍正常：击杀开启、续杀刷新、HUD 倒计时、结束沉睡、死亡/换英雄清理都正常。
- [ ] 猎空自动回溯仍正常：每条命一次，债务状态和属性恢复正常。
- [ ] 布丽吉塔盾击瞬移仍正常：目标筛选、传送位置、眩晕和 4 秒冷却正常。
- [ ] 布丽吉塔盾反仍正常：举盾被近战命中时眩晕攻击者，攻击者短冷却正常。
- [ ] 路霸钩中后的下一次近战强化击退仍正常，只触发一次。
- [ ] 卢西奥落地冲击仍正常，且不会因多个卢西奥或被弹起目标产生无限连锁。
- [ ] 索杰恩滑铲创飞仍正常，同一次滑铲不会连续触发。
- [ ] 伊拉锐召唤太阳仍正常：近战攒层、右键召唤、点名灼烧和清理都符合预期。
- [ ] 芙蕾娅飞天法阵仍正常，法阵效果会清理。
- [ ] 巴蒂假药注射仍正常：概率触发、4 秒左右节流、目标副作用恢复。
- [ ] 安娜睡针特效仍正常：沉睡时显示，醒来后销毁。
- [ ] 禅雅塔雷元素连锁仍正常，不会把临时目标残留到下一次命中。
- [ ] 拉玛刹痛苦核心可被近战摧毁，摧毁者临时目标不会残留。
- [ ] 死神和温斯顿右键仍会被禁用，换到其它英雄后右键恢复。
- [ ] HUD 技能说明仍显示正确英雄内容。
- [ ] 死亡/复活不会残留体型、速度、伤害、承伤、击退、HUD 或特效。
- [ ] 换英雄不会残留旧英雄属性、HUD、冷却或按钮禁用状态。
- [ ] 多名玩家同时触发技能不会互相污染 `player_state` 状态。

## UI 分层

- [ ] 左上角只显示一条“按互动键打开/关闭当前英雄技能说明”入口提示。
- [ ] 按一次互动键打开当前英雄说明，再按一次关闭；不会显示所有英雄说明。
- [ ] 资源/倒计时类 HUD 显示在右侧，例如源氏疯狗时间、托比昂零件、堡垒废铁。
- [ ] 当前持续状态显示在对应资源 HUD 附近，例如托比昂/堡垒当前改装。
- [ ] 关键低频事件使用大字体提示，例如复活甲破碎、疯狗模式开启、非法改装完成。
- [ ] 高频反馈仍保持小字体或不提示，不遮挡近战视野。
- [ ] 死亡、换英雄或状态结束后，对应 HUD 会消失且不会重复创建。

## 基础刀战节奏

- [ ] 大多数英雄血量约在 120 上下，符合当前游戏内房间设置。
- [ ] 普攻伤害约 34 多点，大多数英雄保持三到四下死亡的体感。
- [ ] 蓝盾、护盾或额外生存资源较多的英雄，血量/承伤调整后仍接近三下死亡节奏。
- [ ] 铁拳、斩仇、大锤、小锤等特殊机制英雄的伤害降低符合刀战房体感。

## 小美

- [ ] 小美近战命中是否 +1 寒气。
- [ ] 小美技能 2 是否在准星前方可行走位置生成冰爆陷阱。
- [ ] 冰爆是否有约 0.65 秒预警。
- [ ] 冰爆命中是否 +2 寒气并减速。
- [ ] 冰爆伤害是否只有约 8 点，不能作为主要击杀手段。
- [ ] 小美技能 1 是否开启约 4 秒寒气圈。
- [ ] 敌人在寒气圈内贴近小美时是否每 2 秒 +1 寒气。
- [ ] 寒气最多是否只有 3 层。
- [ ] 寒气满 3 层是否冰冻约 0.6 秒。
- [ ] 冰冻后是否继续减速约 2 秒。
- [ ] 触发满层后寒气是否清零。
- [ ] 3 秒未增加寒气后是否开始衰减。
- [ ] 衰减是否每 2 秒 -1。
- [ ] 衰减过程中重新获得寒气后，是否重新等待 3 秒再衰减。
- [ ] 死亡/换英雄后是否清理寒气、减速、冰冻和特效。
- [ ] 不会永久残留减速、冰冻、HUD 或效果。
- [ ] 旧版 20% 随机冰冻是否已删除或替换，不再靠任意伤害随机冻结。
- [ ] 其它英雄是否不受小美寒气机制影响。

## 拉玛刹

- [ ] 拉玛刹屏幕右侧能看到痛苦值 HUD，例如 `痛苦：0/100`。
- [ ] 拉玛刹造成伤害能给目标施加超重，并显示 `超重：x/3`。
- [ ] 超重会短暂降低目标移动速度、提高引力，并产生向下压的体感。
- [ ] 同一目标能在约 5 秒内累计超重层数。
- [ ] 3 层超重会触发短暂重力压制，目标被击倒约 0.85 秒。
- [ ] 重力压制触发后会清空目标超重层数。
- [ ] 超重层数过期后会清理，目标速度和引力恢复正常。
- [ ] 拉玛刹造成伤害和靠近痛苦核心时能获得痛苦值。
- [ ] 痛苦值满后不会提高拉玛刹常驻伤害。
- [ ] 痛苦值满后下一次近战命中会触发痛苦拳并清空痛苦值。
- [ ] 痛苦拳会给命中目标额外超重层数，帮助触发重力压制。
- [ ] 拉玛刹使用技能 2 能生成痛苦核心，且一次只能存在一个。
- [ ] 拉玛刹靠近痛苦核心时痛苦值会增加。
- [ ] 敌人靠近痛苦核心并近战能摧毁核心。
- [ ] 痛苦核心自然消失或被摧毁时不会造成高伤害。
- [ ] 拉玛刹死亡后会清理痛苦 HUD、核心、痛苦拳冷却和相关状态。
- [ ] 拉玛刹换英雄后会清理痛苦 HUD、核心、痛苦拳冷却和相关状态。
- [ ] 目标死亡或换英雄后会清理超重层数、速度和引力。
- [ ] 其它英雄不会获得拉玛刹痛苦值，也不会误触发痛苦拳。
- [ ] 没有永久残留 HUD、光环、光柱或异常速度/引力。

## 西格玛

- [ ] 西格玛按技能 1 能释放小黑洞。
- [ ] 黑洞位置在西格玛准星前方固定距离附近。
- [ ] 黑洞持续约 3 秒。
- [ ] 黑洞会明显吸引半径约 8 米内的其他存活玩家，但目标仍可操作。
- [ ] 黑洞有蓝紫色光柱、黑色光环和收束爆炸视觉。
- [ ] 西格玛自己不会被自己的黑洞吸引、伤害或炸飞。
- [ ] 黑洞中心约 2 米内会受到少量持续伤害。
- [ ] 单个目标在一次黑洞中心持续伤害中最多受到约 30 点，低于 40 点上限。
- [ ] 黑洞结束时会播放蓝紫爆炸效果，并把附近其他玩家向外炸飞。
- [ ] 黑洞结束伤害为 10 点。
- [ ] 冷却期间不能重复释放小黑洞。
- [ ] 西格玛使用动能俘获/技能 1 结束时，面前会触发一次重力震爆。
- [ ] 重力震爆会对近距离其他玩家造成少量伤害、小幅推开和短暂减速。
- [ ] 重力震爆不会影响西格玛自己。
- [ ] 重力震爆不会覆盖正在运行的小黑洞位置。
- [ ] 西格玛死亡或换英雄后不会残留黑洞特效、冷却状态或伤害计数。
- [ ] 死斗或混战环境下，附近其他玩家都能被影响，不依赖敌方队伍筛选。
- [ ] 其它英雄不会误触发小黑洞。

## 死神

- [ ] 死神右键技能已关闭，按右键不会触发原本右键技能。
- [ ] 温斯顿右键蓄力子弹已关闭，按右键不会触发蓄力子弹。
- [ ] 死神造成最后一击后，会在死者位置生成亡魂锚点。
- [ ] 亡魂锚点有黑色/紫色黑雾或幽灵风格特效。
- [ ] 亡魂锚点约 7 秒后自动消失。
- [ ] 亡魂锚点存在期间，死神按 E / 技能 2 可以借魂传送到锚点。
- [ ] 借魂传送时有明显黑雾/幽灵爆发特效。
- [ ] 借魂成功后，死神周围会短暂出现黑雾猎场。
- [ ] 黑雾猎场会短暂影响周围其他玩家，不会直接秒人。
- [ ] 黑雾猎场效果会正常清理，不会永久残留。
- [ ] 死神死亡后不会残留锚点、黑雾猎场、速度异常或追猎冷却异常。
- [ ] 死神换英雄后不会残留任何死神状态，并会恢复右键。
- [ ] 其它英雄不会生成亡魂锚点，也不会误触发借魂追猎。

## 禅雅塔

- [ ] 禅雅塔按换弹键能按固定顺序切换火、冰、雷。
- [ ] 切换不是随机的，每次按键只前进一相。
- [ ] 切换时会显示“当前元素：火/冰/雷”提示。
- [ ] 火元素普攻有火焰爆炸视觉，并只造成很低额外伤害。
- [ ] 火元素右键会在前方生成弱化火焰爆点。
- [ ] 冰元素普攻有冰霜视觉，并让目标短暂减速。
- [ ] 冰元素右键会在前方生成寒气区域，范围内目标短暂减速。
- [ ] 雷元素普攻有电流视觉，并会轻量连锁到附近一个目标。
- [ ] 雷元素右键会生成短暂磁暴球视觉、电流连线，并以低频率电击附近玩家。
- [ ] 终极技能触发时有多次金色预警、法阵感光环和从高处落下的圣光光柱。
- [ ] 所有新增额外伤害单次都不超过 10。
- [ ] 持续/多段伤害每一跳都不超过 10，频率不会过高。
- [ ] 雷右键和圣光预警特效会清理，不会永久残留。

## 半藏

- [ ] 半藏按技能 1 会在准星前方地面生成预警法阵。
- [ ] 预警约 0.7 秒后开始落箭。
- [ ] 箭雨持续约 2.5 秒。
- [ ] 范围内其他玩家会受到约每秒 10 点的小额持续伤害。
- [ ] 范围内其他玩家会被短暂减速，离开或每次结算后会恢复速度。
- [ ] 半藏自己不会受到箭雨伤害或减速。
- [ ] 箭雨法阵和光柱会在结束、死亡或换英雄时清理。
- [ ] 半藏空中可以额外踏空多段跳。
- [ ] 落地后多段跳次数会重置。
- [ ] 其它英雄不会触发箭雨令或半藏多段跳。

## 奥丽莎

- [ ] 奥丽莎主武器仍然不是主要玩法。
- [ ] 奥丽莎技能 1 期间命中敌人能获得裁决能量。
- [ ] 非技能 1 期间命中敌人有约 30% 概率获得裁决能量。
- [ ] 裁决能量最多 7 层。
- [ ] 奥丽莎每层裁决能量是否增加约 2% 移速，7 层约 +14%。
- [ ] 高频命中不会瞬间异常刷满 7 层。
- [ ] 奥丽莎击杀目标的那次有效命中也能获得裁决能量。
- [ ] 奥丽莎能看到当前裁决能量层数。
- [ ] 7 层时有明显“裁决已满”提示。
- [ ] 右键标枪已开放。
- [ ] 右键标枪基础伤害被削弱到约 20 到 30。
- [ ] 没有裁决能量时，标枪不会触发额外裁决。
- [ ] 1-2 层、3-4 层、5-6 层、7 层裁决效果逐级增强。
- [ ] 标枪触发裁决后，裁决能量清零。
- [ ] 目标被减速后能恢复正常。
- [ ] 目标技能冷却增加不会永久异常。
- [ ] 奥丽莎死亡后裁决能量不会清空。
- [ ] 奥丽莎换英雄后裁决能量清空。
- [ ] 其它英雄不受影响。

- [ ] 禅雅塔死亡后不会残留元素状态、冷却、磁暴球或圣光特效。

- [ ] 被冰元素影响的玩家会恢复正常移动速度。
- [ ] 其它英雄不会触发三相念珠。

## 卢西奥

- [ ] 自己落地不会把自己弹起来。
- [ ] 半径恢复到约 8 米，但仍然不会影响卢西奥自己。
- [ ] 附近其他玩家会被向上弹起。
- [ ] 不会因为自己或其他卢西奥落地造成无限连环触发。
- [ ] 卢西奥自己只获得短暂加速，不被落地冲击弹飞。

## 天使

- [ ] 每次出生有一次复活甲。
- [ ] 致命伤触发后生命约为 60。
- [ ] 复活甲消耗后，本条命不会再次触发。
- [ ] 周围敌人被击退，队友不应被击退。
- [ ] 自己获得约 1 秒无敌。
- [ ] HUD 显示“复活甲已破碎”。
- [ ] 第二次致命伤正常阵亡，重生后重新获得复活甲。

## 源氏

- [ ] 普通状态下 Shift 不能使用，或会被立刻设置为超长冷却。
- [ ] 源氏击杀后进入 8 秒疯狗窗口。
- [ ] 非正式开局/调试状态下，源氏击杀也能开启疯狗窗口。
- [ ] 源氏屏幕上显示疯狗时间倒计时 HUD。
- [ ] 源氏疯狗模式开启时显示大字体“疯狗模式开启”。
- [ ] 疯狗窗口内 Shift 可用。
- [ ] 疯狗窗口内大招可用，终极充能变为 100。
- [ ] 击杀后不需要手动按 Q，源氏应立刻进入龙刃状态。
- [ ] 疯狗窗口内再次击杀会把时间重置为 8 秒。
- [ ] 疯狗窗口自然结束后源氏沉睡 5 秒。
- [ ] 疯狗窗口自然结束后倒计时 HUD 消失。
- [ ] 源氏死亡后不会残留疯狗窗口，也不会延迟触发沉睡。
- [ ] 换英雄后不会残留疯狗窗口。
- [ ] 大招伤害约为 70；如果龙刃单次仍明显超过 70，需要回看 `事件技能 == 终极技能` 是否识别失败。
- [ ] 其它英雄不受影响。

## 士兵 76

- [ ] 初始体型为 1，伤害和移速为 100。
- [ ] 左键每次只变大 1 档，不会按住后一瞬间跳到最大。
- [ ] 右键每次只变小 1 档，不会按住后一瞬间跳到最小。
- [ ] 变大档位依次为 `2 / 4 / 8 / 16 / 32`，最大为 `32`。
- [ ] 变小档位依次为 `0.75 / 0.5 / 0.25 / 0.1 / 0.01`，最小为 `0.01`。
- [ ] 体型越大，语音音调越低，伤害逐档降低，最大体型伤害约为 70%。
- [ ] 体型越小，语音音调越高，移动速度逐档提高，最小体型移速约为 130%。
- [ ] 死亡或换英雄后体型、音调、伤害、速度都恢复正常。
- [ ] 旧的长时间变大持续伤害不再触发。

## 猎空

- [ ] 每条命有一次自动赖账回溯机会。
- [ ] 非致命伤害不会触发自动回溯。
- [ ] 致命伤触发后猎空不应真正死亡，屏幕显示“时间赖账成功”。
- [ ] 触发时回溯冷却被重置，并强制使用 E / 技能 2。
- [ ] 同一条命第二次致命伤不会再次自动回溯。
- [ ] 约 3 秒后进入还债状态，并显示“时间债务到期”。
- [ ] 还债状态持续约 4 秒，期间体型约 1.25、移速约 85%、受到伤害约 125%。
- [ ] 还债结束后体型、移速、受到伤害恢复正常。
- [ ] 死亡或换英雄会清理自动回溯机会和还债状态，不会把异常属性带到其它英雄。

## 堡垒

- [ ] 堡垒屏幕上能看到废铁 HUD，例如 `废铁：0/6`。
- [ ] 堡垒造成正数伤害会获得 1 个废铁。
- [ ] 废铁最多到 `6/6`，满 6 后自动触发随机非法改装。
- [ ] 高频伤害不会一秒内异常刷满废铁，废铁获取有明显节流。
- [ ] 改装触发后废铁立刻清零。
- [ ] 改装触发后右上角显示当前改装状态，例如 `当前改装：破甲机枪`。
- [ ] 改装计时结束、死亡或换英雄后，当前改装状态 HUD 会消失。
- [ ] 破甲机枪：约 6 秒内造成伤害提高、受到伤害提高，并有红/橙色过载效果。
- [ ] 铁皮乌龟：约 6 秒内受到伤害降低、移速大幅降低、体型略大，并有蓝/白色装甲效果。
- [ ] 迷你履带：约 6 秒内体型变小、移速提高、伤害降低、受到击退提高，并有黄/蓝色改装效果。
