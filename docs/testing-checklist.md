# 进游戏测试清单

## UI 分层

- [ ] 左上角只显示一条“按互动键打开/关闭当前英雄技能说明”入口提示。
- [ ] 按一次互动键打开当前英雄说明，再按一次关闭；不会显示所有英雄说明。
- [ ] 资源/倒计时类 HUD 显示在右侧，例如源氏疯狗时间、托比昂零件、堡垒废铁。
- [ ] 当前持续状态显示在对应资源 HUD 附近，例如托比昂/堡垒当前改装。
- [ ] 关键低频事件使用大字体提示，例如复活甲破碎、疯狗模式开启、非法改装完成。
- [ ] 高频反馈仍保持小字体或不提示，不遮挡近战视野。
- [ ] 死亡、换英雄或状态结束后，对应 HUD 会消失且不会重复创建。

## 基础刀战节奏

- [ ] 大多数英雄血量约在 120 上下，符合当前游戏内房间设置。
- [ ] 普攻伤害约 34 多点，大多数英雄保持三到四下死亡的体感。
- [ ] 蓝盾、护盾或额外生存资源较多的英雄，血量/承伤调整后仍接近三下死亡节奏。
- [ ] 铁拳、斩仇、大锤、小锤等特殊机制英雄的伤害降低符合刀战房体感。

## 拉玛刹

- [ ] 拉玛刹屏幕右侧能看到痛苦值 HUD，例如 `痛苦：0/100`。
- [ ] 拉玛刹造成伤害能给目标施加超重，并显示 `超重：x/3`。
- [ ] 超重会短暂降低目标移动速度、提高引力，并产生向下压的体感。
- [ ] 同一目标能在约 5 秒内累计超重层数。
- [ ] 3 层超重会触发短暂重力压制，目标被击倒约 0.85 秒。
- [ ] 重力压制触发后会清空目标超重层数。
- [ ] 超重层数过期后会清理，目标速度和引力恢复正常。
- [ ] 拉玛刹造成伤害和靠近痛苦核心时能获得痛苦值。
- [ ] 痛苦值满后不会提高拉玛刹常驻伤害。
- [ ] 痛苦值满后下一次近战命中会触发痛苦拳并清空痛苦值。
- [ ] 痛苦拳会给命中目标额外超重层数，帮助触发重力压制。
- [ ] 拉玛刹使用技能 2 能生成痛苦核心，且一次只能存在一个。
- [ ] 拉玛刹靠近痛苦核心时痛苦值会增加。
- [ ] 敌人靠近痛苦核心并近战能摧毁核心。
- [ ] 痛苦核心自然消失或被摧毁时不会造成高伤害。
- [ ] 拉玛刹死亡后会清理痛苦 HUD、核心、痛苦拳冷却和相关状态。
- [ ] 拉玛刹换英雄后会清理痛苦 HUD、核心、痛苦拳冷却和相关状态。
- [ ] 目标死亡或换英雄后会清理超重层数、速度和引力。
- [ ] 其它英雄不会获得拉玛刹痛苦值，也不会误触发痛苦拳。
- [ ] 没有永久残留 HUD、光环、光柱或异常速度/引力。

## 西格玛

- [ ] 西格玛按技能 1 能释放小黑洞。
- [ ] 黑洞位置在西格玛准星前方固定距离附近。
- [ ] 黑洞持续约 3 秒。
- [ ] 黑洞会轻微吸引半径约 6 米内的其他存活玩家。
- [ ] 西格玛自己不会被自己的黑洞吸引、伤害或炸飞。
- [ ] 黑洞中心约 2 米内会受到少量持续伤害。
- [ ] 单个目标在一次黑洞中心持续伤害中最多受到约 30 点，低于 40 点上限。
- [ ] 黑洞结束时会播放爆炸效果，并把附近其他玩家向外炸飞。
- [ ] 黑洞结束伤害为 10 点。
- [ ] 冷却期间不能重复释放小黑洞。
- [ ] 西格玛死亡或换英雄后不会残留黑洞特效、冷却状态或伤害计数。
- [ ] 死斗或混战环境下，附近其他玩家都能被影响，不依赖敌方队伍筛选。
- [ ] 其它英雄不会误触发小黑洞。

## 卢西奥

- [ ] 自己落地不会把自己弹起来。
- [ ] 半径恢复到约 8 米，但仍然不会影响卢西奥自己。
- [ ] 附近其他玩家会被向上弹起。
- [ ] 不会因为自己或其他卢西奥落地造成无限连环触发。
- [ ] 卢西奥自己只获得短暂加速，不被落地冲击弹飞。

## 天使

- [ ] 每次出生有一次复活甲。
- [ ] 致命伤触发后生命约为 60。
- [ ] 复活甲消耗后，本条命不会再次触发。
- [ ] 周围敌人被击退，队友不应被击退。
- [ ] 自己获得约 1 秒无敌。
- [ ] HUD 显示“复活甲已破碎”。
- [ ] 第二次致命伤正常阵亡，重生后重新获得复活甲。

## 源氏

- [ ] 普通状态下 Shift 不能使用，或会被立刻设置为超长冷却。
- [ ] 源氏击杀后进入 8 秒疯狗窗口。
- [ ] 非正式开局/调试状态下，源氏击杀也能开启疯狗窗口。
- [ ] 源氏屏幕上显示疯狗时间倒计时 HUD。
- [ ] 源氏疯狗模式开启时显示大字体“疯狗模式开启”。
- [ ] 疯狗窗口内 Shift 可用。
- [ ] 疯狗窗口内大招可用，终极充能变为 100。
- [ ] 击杀后不需要手动按 Q，源氏应立刻进入龙刃状态。
- [ ] 疯狗窗口内再次击杀会把时间重置为 8 秒。
- [ ] 疯狗窗口自然结束后源氏沉睡 5 秒。
- [ ] 疯狗窗口自然结束后倒计时 HUD 消失。
- [ ] 源氏死亡后不会残留疯狗窗口，也不会延迟触发沉睡。
- [ ] 换英雄后不会残留疯狗窗口。
- [ ] 大招伤害约为 70；如果龙刃单次仍明显超过 70，需要回看 `事件技能 == 终极技能` 是否识别失败。
- [ ] 其它英雄不受影响。

## 士兵 76

- [ ] 初始体型为 1，伤害和移速为 100。
- [ ] 左键每次只变大 1 档，不会按住后一瞬间跳到最大。
- [ ] 右键每次只变小 1 档，不会按住后一瞬间跳到最小。
- [ ] 变大档位依次为 `2 / 4 / 8 / 16 / 32`，最大为 `32`。
- [ ] 变小档位依次为 `0.75 / 0.5 / 0.25 / 0.1 / 0.01`，最小为 `0.01`。
- [ ] 体型越大，语音音调越低，伤害逐档降低，最大体型伤害约为 70%。
- [ ] 体型越小，语音音调越高，移动速度逐档提高，最小体型移速约为 130%。
- [ ] 死亡或换英雄后体型、音调、伤害、速度都恢复正常。
- [ ] 旧的长时间变大持续伤害不再触发。

## 猎空

- [ ] 每条命有一次自动赖账回溯机会。
- [ ] 非致命伤害不会触发自动回溯。
- [ ] 致命伤触发后猎空不应真正死亡，屏幕显示“时间赖账成功”。
- [ ] 触发时回溯冷却被重置，并强制使用 E / 技能 2。
- [ ] 同一条命第二次致命伤不会再次自动回溯。
- [ ] 约 3 秒后进入还债状态，并显示“时间债务到期”。
- [ ] 还债状态持续约 4 秒，期间体型约 1.25、移速约 85%、受到伤害约 125%。
- [ ] 还债结束后体型、移速、受到伤害恢复正常。
- [ ] 死亡或换英雄会清理自动回溯机会和还债状态，不会把异常属性带到其它英雄。

## 堡垒

- [ ] 堡垒屏幕上能看到废铁 HUD，例如 `废铁：0/6`。
- [ ] 堡垒造成正数伤害会获得 1 个废铁。
- [ ] 废铁最多到 `6/6`，满 6 后自动触发随机非法改装。
- [ ] 高频伤害不会一秒内异常刷满废铁，废铁获取有明显节流。
- [ ] 改装触发后废铁立刻清零。
- [ ] 改装触发后右上角显示当前改装状态，例如 `当前改装：破甲机枪`。
- [ ] 改装计时结束、死亡或换英雄后，当前改装状态 HUD 会消失。
- [ ] 破甲机枪：约 6 秒内造成伤害提高、受到伤害提高，并有红/橙色过载效果。
- [ ] 铁皮乌龟：约 6 秒内受到伤害降低、移速大幅降低、体型略大，并有蓝/白色装甲效果。
- [ ] 迷你履带：约 6 秒内体型变小、移速提高、伤害降低、受到击退提高，并有黄/蓝色改装效果。
- [ ] 废铁爆仓：约 2 秒内体型变大、移速降低、受到伤害提高并短暂击倒，然后恢复。
- [ ] 堡垒死亡不会清空废铁。
- [ ] 堡垒死亡会恢复体型、速度、伤害、承伤、击退，不会残留改装属性。
- [ ] 换英雄会清空废铁、销毁废铁 HUD、恢复所有属性。
- [ ] 其它英雄造成伤害不会获得废铁，也不会受堡垒规则影响。

## 巴蒂 - 哈哈镜

- [ ] 巴蒂斯特开大时触发哈哈镜。
- [ ] 半径 8 米内玩家获得本次随机变形。
- [ ] 当前第一版同一次开大范围内玩家获得同一种镜像效果。
- [ ] 变形持续约 6 秒。
- [ ] 6 秒后体型、速度、伤害、承伤、击退恢复正常。
- [ ] 不会把人弹起来。
- [ ] 巴蒂死亡或换英雄后不会继续重复触发哈哈镜。

## 巴蒂 - 假药注射

- [ ] 巴蒂斯特造成伤害时有约 18% 概率触发。
- [ ] 触发后目标获得一种随机副作用。
- [ ] 目标 3 秒后恢复正常。
- [ ] 巴蒂 4 秒内不会重复触发。
- [ ] 同一目标不会叠多个假药状态。
- [ ] 不会造成额外伤害。
- [ ] 不会影响其它英雄的触发逻辑。

## 托比昂

- [ ] 托比昂屏幕上能看到零件 HUD，初始为 `0/3`。
- [ ] 托比昂每次参与击杀获得 1 个零件，不需要必须造成最后一击。
- [ ] 零件最多到 `3/3`，满后提示“非法改装就绪”。
- [ ] 零件满后按 E / 技能 2 触发一次随机非法改装。
- [ ] 改装触发后零件立刻清零。
- [ ] 托比昂改装结果用大字体显示，例如“非法改装：巨型模块”。
- [ ] 托比昂改装完成后右上角显示当前改装状态，例如 `当前改装：巨型模块`。
- [ ] 失败改装结束、死亡或换英雄后，当前改装状态 HUD 会消失。
- [ ] 成功改装持续期间击杀不会继续累积零件。
- [ ] 巨型模块：体型变大、伤害提高、速度降低、受到击退增加。
- [ ] 迷你模块：体型变小、速度提高、伤害降低、受到击退增加。
- [ ] 防爆模块：体型变大一点、承伤降低、速度和伤害降低、受到击退降低。
- [ ] 失败模块：短暂变大、变慢、易受伤并被击倒，约 2 秒后恢复。
- [ ] 成功改装死亡或换英雄后，体型、速度、伤害、承伤、击退全部恢复。
- [ ] 死亡、换英雄、离开托比昂后零件和改装状态清空。
- [ ] 换出托比昂后零件 HUD 消失，切回托比昂只创建一个 HUD。

## 索杰恩

- [ ] 滑铲靠近目标会触发。
- [ ] 目标受到 20 点伤害。
- [ ] 目标被击倒约 1.25 秒并铲飞。
- [ ] 索杰恩自己不受伤、不被击倒、不被推开。
- [ ] 同一次滑铲不会连续触发很多次。
- [ ] 半径约 2.6，推力约 18，手感不过分夸张。

## 温斯顿

- [ ] 温斯顿使用技能 1 靠近正面玩家会触发猩猩抱摔。
- [ ] 温斯顿每次跳跃最多抓 1 人。
- [ ] 温斯顿不会抓自己。
- [ ] 目标会被绑定到温斯顿身上或身前。
- [ ] 温斯顿落地后目标会被释放。
- [ ] 落地后目标会短暂击倒或击晕。
- [ ] 抱摔不造成伤害。
- [ ] 抱摔不造成范围伤害。
- [ ] 抱摔不会连续重复触发。
- [ ] 温斯顿死亡时状态能清理。
- [ ] 目标死亡时状态能清理。
- [ ] 温斯顿换英雄时状态能清理。
- [ ] 目标换英雄时状态能清理。
- [ ] 不会出现永久绑定、永久击晕、永久禁用按钮。
- [ ] 其它英雄不受影响。

## 布丽吉塔

- [ ] 布丽吉塔举盾攻击远处目标可以触发盾击瞬移。
- [ ] 目标太近不会触发。
- [ ] 目标太远不会触发。
- [ ] 没有视线不会触发。
- [ ] 准星没有目标不会触发。
- [ ] 成功后布丽吉塔会传送到目标附近。
- [ ] 目标只被眩晕，不受额外伤害。
- [ ] 成功后有冷却，不能连续触发。
- [ ] 触发失败不浪费冷却。
- [ ] 换英雄或死亡后不残留状态。
- [ ] 其它英雄不受影响。

## 伊拉锐

- [ ] 造成伤害有约 20% 概率触发晒黑。
- [ ] 晒黑目标变大、变慢、受到击退增加。
- [ ] 晒黑持续约 4 秒后恢复。
- [ ] 再次命中晒黑目标会小幅向上弹飞。
- [ ] 二次弹飞不会因为连续伤害疯狂触发。
- [ ] 技能 2 会弹开附近其他玩家。
- [ ] 技能 2 对空中目标有额外向上弹飞。
- [ ] 伊拉锐自己不会被弹开，并会经历加速、短暂减速、恢复。

## 芙蕾娅

- [ ] 按 E 技能触发时地面出现法阵。
- [ ] 约 0.35 秒后范围内玩家一起高飞。
- [ ] 冷却期间不会重复触发。
- [ ] 范围约 6，高度符合娱乐效果。
- [ ] 法阵效果会自动消失，不会残留。
- [ ] 确认 E 技能触发稳定，不会由普通跳跃触发。

## 安娜

- [ ] 睡针命中后目标有明显玫红光环/标记。
- [ ] 被睡玩家看到“你被睡了”提示。
- [ ] 醒来后标记消失。
- [ ] 不会在沉睡期间一直创建新特效。
- [ ] 原有沉睡冷却惩罚仍然只触发一次，不刷屏。

## HUD 技能说明

- [ ] 左上角显示“按互动键打开/关闭当前英雄技能说明”。
- [ ] 按一下互动键显示当前英雄的技能说明，不再显示全英雄合集。
- [ ] 再按一下互动键后技能说明 HUD 消失。
- [ ] 按住互动键不会导致说明 HUD 反复闪烁。
- [ ] 切换不同英雄后，按互动键能看到对应英雄说明。
- [ ] 说明文字比旧版大字体合集更易读，没有严重遮挡。
