# OW Knife Room

OW Knife Room 是一个 Overwatch 2 娱乐刀战房创意工坊模式，主打近战、三下死亡、二段跳、角色特色整活技能和朋友局快乐混战。

这个模式不是严肃竞技平衡。它更像一场带着技能整活的近身乱斗：接近、骗技能、二段跳、反杀、被奇怪机制坑一下，然后笑着再来一把。

## 核心玩法

- 娱乐刀战房，大多数英雄主要靠近战打架。
- 大多数英雄不能按正常枪战方式使用主要武器，战斗重点是近身、走位和技能整活。
- 大多数英雄大约三次攻击死亡，节奏短促，容易打出反杀。
- 蓝盾、护盾或额外生存资源较多的英雄，会按房间平衡方向调整血量或承伤，尽量保持接近“三下死亡”的体感。
- 所有角色拥有二段跳，这是本房间的核心移动机制。
- 多个英雄有专属娱乐技能，强效果通常伴随副作用、冷却、持续时间或状态清理。
- 适合朋友局快乐混战，不追求严肃排位式公平。

## 基础规则

### 近战为主

这是刀战房，不是正常枪战房。大多数英雄的主要攻击会受到限制，主要依靠近战和少量保留技能进行战斗。

近战之外的技能更多用于接近、逃生、扰乱、整活或触发角色特色机制。后续新增技能时，也应该优先服务近战节奏，而不是把远程输出变成最强玩法。

### 三下死亡

本房间的核心节奏是“大多数英雄大约被打三下就会死亡”。这让战斗更短、更紧张，也让二段跳、走位和技能时机变得更重要。

个别英雄因为护盾、蓝盾或额外生存资源较多，会有额外血量或伤害平衡。README 不记录精确血量和伤害数值，具体数值以当前 Workshop 房间设置和源码为准。

### 特殊机制英雄

铁拳、斩仇、大锤、小锤这类英雄的主要输出方式天然更接近近战或近战形态，不能完全按普通角色处理。

当前 README 将它们记录为平衡方向：这类英雄应通过降低伤害、限制收益或调整血量来保持刀战房节奏。当前 OverPy 源码里没有看到这四个英雄完整独立规则，具体数值需要以房间设置为准，后续维护时建议补进文档或源码注释。

### 全员二段跳

所有角色默认拥有二段跳。

- 第一次跳跃后，空中可以再次跳跃一次。
- 二段跳用于接近、躲避、追击和制造近战角度。
- 落地后会恢复二段跳次数。

### 通用状态与反馈

- 击杀会触发回血提示和短暂治疗。
- 被入侵时会变大并持续受到伤害。
- 被睡眠时会进入技能冷却惩罚，并显示明显睡眠标记。
- 按互动键可以打开或关闭当前英雄的技能说明。

## 角色特色技能

### 士兵：76：蚁人 76

士兵：76 可以通过攻击键调整自己的体型，在巨大和微小之间切换。

- 左键让体型逐档变大，右键让体型逐档变小。
- 当前档位从极小到巨大，共多档变化，最大可以非常夸张，最小可以缩到很难被看见。
- 变大后伤害会按档位降低，体型越夸张越显眼，风险越高。
- 变小后移动速度会提高，适合绕后、追击和整活。
- 音调会随体型变化，强化“蚁人”效果。
- 死亡或换英雄后会恢复体型、伤害、速度和音调，避免状态残留。

### 天使：复活甲

天使每条命拥有一次复活甲，用来赖掉一次致命伤。

- 每次出生后获得一次复活甲。
- 受到致命伤时，会把生命拉回到约 60，并消耗复活甲。
- 复活甲破碎时会震开周围敌人，并给天使短暂无敌。
- 本条命复活甲消耗后不会再次触发，死亡后下一条命重新获得。
- 触发时会显示“复活甲已破碎”，让玩家知道保命机会已经用掉。

### 猎空：自动赖账回溯

猎空每条命拥有一次自动保命机会。

- 受到致命伤时，会尝试把本次死亡赖掉。
- 自动触发时会重置回溯冷却，并强制按下 E / 技能 2。
- 触发后提示“时间赖账成功”，本条命的自动回溯机会被消耗。
- 约 3 秒后进入“还债状态”：体型变大、速度降低、受到伤害提高。
- 还债持续约 4 秒，结束后恢复正常。
- 死亡或换英雄会清理自动回溯和还债状态。

### 源氏：疯狗龙刃窗口

源氏不再是无限击杀刷新 Shift，而是击杀后进入短时间爆发窗口。

- 普通状态下，源氏的 Shift 会被锁住或保持极长冷却。
- 源氏造成最后一击后，进入 8 秒“疯狗模式”。
- 窗口内会解锁 Shift，并自动给予大招可用状态。
- 窗口内再次击杀会把剩余时间刷新回 8 秒。
- 窗口结束后，源氏会沉睡约 5 秒，给其他玩家反制机会。
- 窗口内源氏伤害被限制为较低水平，用来避免完全失控。
- 死亡或换英雄会清理窗口、HUD 和属性调整。

### 托比昂：非法改装

托比昂通过参与击杀收集零件，满零件后可以启动一次随机非法改装。

- 参与击杀会获得零件，最多 3 个。
- 右侧 HUD 会显示当前零件数量。
- 零件满后，使用 E / 技能 2 触发随机改装，并立刻清空零件。
- 改装可能变成巨型模块、迷你模块、防爆模块，也可能失败。
- 成功改装会改变体型、速度、伤害、承伤或击退，并在右上角显示当前改装状态。
- 失败改装会短暂变大、变慢、变脆并被击倒，随后恢复。
- 死亡或换英雄会清空零件和改装状态，并恢复属性。

### 堡垒：废铁非法改装

堡垒通过造成伤害攒废铁，满 6 个后自动随机改装。

- 造成正数伤害会获得 1 个废铁。
- 废铁最多 6 个，右侧 HUD 显示当前废铁数。
- 废铁获取有短冷却，避免高频伤害一瞬间刷满。
- 满 6 个后自动触发随机非法改装，并立刻清零。
- 改装包括破甲机枪、铁皮乌龟、迷你履带和废铁爆仓。
- 破甲机枪提高输出，但自己也更脆。
- 铁皮乌龟更硬但更慢，体型略微变大。
- 迷你履带更小更快，但伤害降低且更容易被击退。
- 废铁爆仓是失败惩罚，会短暂变大、变慢、变脆并被击倒。
- 堡垒死亡不会清空废铁，但会清理异常属性；换英雄会清空废铁和相关状态。

### 巴蒂斯特：哈哈镜与假药

巴蒂斯特有两个娱乐机制：大招触发哈哈镜，造成伤害有概率触发假药副作用。

- 使用大招时，会触发“增幅矩阵哈哈镜”。
- 哈哈镜会影响附近玩家，让他们进入随机变形状态。
- 变形可能是极大、极小、玻璃人或铁块，不同效果会改变体型、速度、伤害或承伤。
- 哈哈镜持续约 6 秒，结束后恢复属性。
- 巴蒂造成伤害时，有概率让目标获得“假药注射”副作用。
- 假药副作用持续约 3 秒，可能让目标变大、缩水、兴奋过量或被镇定。
- 假药有内置冷却，同一目标不会无限叠加。

### 小美：冰冻拳

小美的攻击带有概率冰冻效果。

- 小美造成伤害时，有约 20% 概率冰冻目标。
- 冰冻持续约 1 秒。
- 概率按每次造成伤害独立判定。
- 这是短控制效果，不应该成为无限冻结链。

### 路霸：钩中改造

路霸钩中敌人后，会给目标和自己都带来短暂变化。

- 钩中目标后，目标体型会缩小到约 0.5 倍，持续约 3 秒。
- 目标移动速度提高，但受到击退也增加，更容易被打飞。
- 路霸获得一次强化近战机会。
- 下一次近战命中会附加强击退，然后消耗该强化。
- 该机制鼓励钩中后接近战，而不是只靠钩子本身决定胜负。

### 卢西奥：落地冲击

卢西奥从空中落地时可以制造范围弹跳。

- 卢西奥曾经在空中，落地时会触发落地冲击。
- 附近其他玩家会被向上弹起，卢西奥自己不会被弹起来。
- 卢西奥自己获得短暂加速。
- 该效果有冷却，避免落地后无限连环触发。
- 当前范围偏娱乐向，适合在人群中制造混乱。

### 索杰恩：滑铲创飞

索杰恩滑铲靠近玩家时，会把附近玩家创飞。

- 使用滑铲靠近其他玩家时触发。
- 半径较小，索杰恩自己不受影响。
- 目标会受到少量伤害、被击倒并被推开。
- 有短冷却，避免一次滑铲连续触发十几次。
- 这个技能更像近身冲撞，不是远程爆发。

### 伊拉锐：晒黑与爆发

伊拉锐有“晒黑”和“爆发弹开”两个机制。

- 伊拉锐造成伤害时，有概率让目标进入晒黑状态。
- 晒黑目标会变大、变慢、受到击退增加，持续约 4 秒。
- 再次命中正在晒黑的目标，会把目标小幅向上弹起。
- 晒黑有内置冷却，避免频繁刷新。
- 使用技能 2 / 爆发时，会弹开附近其他玩家。
- 伊拉锐自己会短暂加速，随后短暂减速，再恢复正常。

### 芙蕾娅：飞天法阵

芙蕾娅使用 E 技能时会制造飞天法阵。

- 按 E / 技能 2 触发。
- 法阵会在脚下出现明显特效。
- 短暂前摇后，范围内玩家会一起被高高弹起。
- 这个效果默认偏娱乐，范围内玩家不分敌我。
- 法阵特效会被清理，并带有冷却。

### 安娜：睡眠标记与激素控制

安娜的睡眠相关效果会更醒目，并保留一个娱乐向大招控制。

- 任意玩家被睡眠时，会出现明显睡眠标记。
- 被睡玩家的技能会进入较长冷却，并调整终极技能充能。
- 醒来后睡眠标记会被清理。
- 安娜大招按下时，可以让视角附近目标沉睡一小段时间。
- 这些效果主要用于制造控制和反制窗口。

### 雾子：法阵击倒

雾子使用技能 2 时可以生成短暂击倒法阵。

- 使用技能 2 会生成光束、光柱和光环效果。
- 法阵范围内玩家会被短暂击倒。
- 法阵持续约 5 秒后结束。
- 效果实体会保存并清理，避免永久残留。

### 黑影相关：被入侵惩罚

当前源码里有通用“被入侵”惩罚规则，任何玩家进入被入侵状态都会受到影响。

- 被入侵时，玩家体型会变大。
- 被入侵期间会持续受到伤害。
- 被入侵结束后会尝试恢复体型并清理效果。
- 这部分是旧规则迁移保留下来的机制，后续仍建议继续检查效果句柄和重复触发风险。

## 计划中 / 待确认

这些内容是设计方向或需要继续确认的平衡项，不要当作完整已实装技能理解：

- 主要武器限制、三下死亡血量和部分英雄生命值调整，可能主要来自 Workshop 房间设置；当前 OverPy 规则里没有完整展开。
- 铁拳、斩仇、大锤、小锤的伤害降低属于刀战房平衡方向，当前 README 不记录精确数值，后续建议补充到源码或设置文档。
- 被入侵惩罚和部分旧规则仍有重复触发/句柄清理风险，后续可以继续重构。
- 主机调试机器人生成仍建议加防连发。

## 如何游玩

- 进入房间后选择英雄。
- 大多数英雄不能按正常枪战方式输出，主要依靠近战。
- 大多数英雄约三下死亡，注意走位、距离和二段跳。
- 利用二段跳接近、躲避、追击或绕开敌人的正面。
- 按互动键查看当前英雄技能说明，再按一次关闭。
- 注意右侧 HUD：它通常显示资源、倒计时或当前状态。
- 有些强力技能会带副作用，例如变脆、变慢、睡眠或状态结束惩罚。
- 死亡、换英雄或状态结束后，异常体型、速度、伤害和 HUD 理论上都应该被清理。

## 开发与维护

本项目用于长期维护娱乐刀战房。后续新增角色技能时，请同步更新 README、测试清单和变量文档。

- 已实装技能写进 README 的“角色特色技能”。
- 只在 TODO 或计划里出现的内容，放到“计划中 / 待确认”，不要写成已实装。
- 每次修改平衡，建议同步更新 `docs/testing-checklist.md`。
- 每次新增玩家变量，必须更新 `docs/variable-map.md`。
- UI 新增或调整时，遵守 `docs/ui-guidelines.md`。
- 不直接修改 `legacy/` 中的旧版 Workshop 文件，旧代码用于回退和审计。

## 测试重点

- 主要攻击是否被正确限制。
- 大多数英雄是否符合约三下死亡的体感。
- 蓝盾、护盾或生存资源多的英雄，血量和承伤是否合适。
- 铁拳、斩仇、大锤、小锤的伤害降低是否符合预期。
- 全员二段跳是否正常。
- 角色特色技能是否能触发、能恢复、不会残留状态。
- 死亡、换英雄后是否清理异常体型、速度、伤害、承伤、击退和 HUD。
- HUD 是否不会重复刷屏。
- 高频伤害触发类技能是否有节流，避免瞬间刷满资源或制造性能问题。
